
# Functions and Recursion in C

This directory contains programs demonstrating the fundamentals and practical implementations of **Functions** and **Recursion** in C programming.

---

## 📌 Overview

- **Functions**: Modular blocks of code designed to perform specific tasks, improving code reusability, organization, and readability.
- **Recursion**: A technique where a function calls itself directly or indirectly to solve a smaller instance of the same problem until a base condition is met.

---

## 🧠 Key Concepts Covered

- **Function Declaration (Prototype)**: Specifying the function's return type, name, and parameters before `main()`.
- **Function Definition**: The actual code and logic executed by the function.
- **Pass by Value vs. Pass by Reference**: Understanding how data is passed into functions.
- **Recursive Base Case**: Ensuring recursion terminates to avoid infinite loops and stack overflow errors.

---

Make sure you have a C compiler installed (such as `gcc` or `clang`).


2. **Compile your program:**
```bash
gcc <filename>.c -o output
```

3. **Run the executable:**
* **Linux / macOS:**
