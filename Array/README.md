
# Arrays in C

Welcome to the **Array** directory of the `Abi_C` repository! This section is dedicated to exploring and implementing array data structures in C.

## 🧠 Concepts Covered

The programs in this folder focus on both fundamental and advanced array concepts, including:

*   **Basic Array Operations:** Declaration, initialization, and accessing elements via indices.
*   **Memory Allocation:** Understanding how arrays are stored contiguously in memory.
*   **Array Traversal:** Using loops (`for`, `while`) to iterate through array elements.
*   **Multi-dimensional Arrays:** Working with 2D arrays (matrices) and understanding their row-major memory layout.
*   **Passing Arrays to Functions:** Understanding how arrays decay into pointers when passed as function arguments.
*   **Array Manipulation:** Inserting, deleting, modifying, and reversing elements within an array.
*   **Searching and Sorting:** Implementing basic algorithms like linear search, binary search, and simple sorting techniques on array data.
*   **Strings as Arrays:** Handling character arrays and understanding the null-terminator (`\0`).

## 🚀 How to Compile and Run

To compile and run any of the C programs in this folder:

1. Open your terminal or command prompt.
2. Navigate to this directory.
3. Compile the code using a C compiler (like GCC):
   ```bash
   gcc <filename>.c -o <output_name>

```

4. Run the compiled executable:
* **Windows:** `<output_name>.exe`
* **Linux/Mac:** `./<output_name>`
