## 🚀 Getting Started

### Prerequisites

You need a C compiler installed on your system:

* **Linux/macOS:** GCC or Clang (`sudo apt install build-essential` or Xcode Command Line Tools)
* **Windows:** MinGW or GCC via WSL

Verify your installation:

```bash
gcc --version

```

### Compiling and Running Programs

1. **Clone the repository:**
```bash
git clone [https://github.com/IamAbinashDas/Abi_C.git](https://github.com/IamAbinashDas/Abi_C.git)
cd Abi_C

```


2. **Navigate to a topic directory:**
```bash
cd Conditions

```


3. **Compile a source file:**
```bash
gcc filename.c -o program

```


4. **Execute the compiled binary:**
```bash
# On Linux/macOS
./program

# On Windows
program.exe

```
